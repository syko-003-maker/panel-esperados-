## 🎨 Design System

### Composants Créés
- **Button:** default, destructive, outline, secondary, ghost, link
- **Card:** container system (Header, Title, Description, Content, Footer)
- **Badge:** 4 variantes (default, secondary, destructive, outline)
- **Input:** clean field with focus/disabled states
- **Select:** dropdown avec Radix-UI
- **Dialog:** modal accessible
- **Dropdown Menu:** menus avec submenus
- **Tabs:** navigation onglets
- **Skeleton:** loading placeholders

### Couleurs
- Background/Foreground (light + dark)
- Card + Popover (with elevation in dark)
- Muted (backgrounds, text)
- Accent (primary color, red by default)
- Destructive (errors, warnings)
- Border + Input colors

### Dark Mode
- Default: light theme
- Auto: respects system preference
- Toggle-ready: add `dark` class to `<html>`
